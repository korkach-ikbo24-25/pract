## Задача 1

Вывести отсортированный в алфавитном порядке список имен пользователей в файле passwd (вам понадобится grep).
## Ответ: 
```
grep '.*' /etc/passwd | cut -d: -f1 | sort
```
---

grep - ищет строки в файле по шаблону<br>
/etc/passwd - файл со списком пользователей системы<br>
cut - вырезает нужную часть из каждой строки<br>
-d: - разделитель полей<br>
-f1 - взять первое поле<br>

## Задача 2

Вывести данные /etc/protocols в отформатированном и отсортированном порядке для 5 наибольших портов, как показано в примере ниже:

```
[root@localhost etc]# cat /etc/protocols ...
142 rohc
141 wesp
140 shim6
139 hip
138 manet
```
## Ответ: 
```
grep -v '^#' /etc/protocols | awk '{print $2, $1}' | sort -rn | head -n 5
```
---

awk '{print $2, $1}'  меняет местами 2-й и 1-й столбцы, awk - построчный обработчик текста<br>
-v инвертирует подбор по регулярному выражению, т.е все что не совпадает с регуляркой<br>
-n - числовая сортировка, r - reverse<br>


## Задача 3

Написать программу banner средствами bash для вывода текстов, как в следующем примере (размер баннера должен меняться!):

```
[root@localhost ~]# ./banner "Hello from RTU MIREA!"
+-----------------------+
| Hello from RTU MIREA! |
+-----------------------+
```

Перед отправкой решения проверьте его в ShellCheck на предупреждения.

## Ответ:

```
#!/bin/bash

text=$*
length=${#text}

for _ in $(seq 1 $((length + 2))); do
    line+="-"
done

echo "+${line}+"
echo "| ${text} |"
echo "+${line}+"
```

---

!/bin/bash - shebang,  указывает, какой интерпретатор использовать<br>
text=$* - сохраняет аргументы в text<br>
length=${#text} - сохраняет длину аргументов в length<br>

## Задача 4

Написать программу для вывода всех идентификаторов (по правилам C/C++ или Java) в файле (без повторений).

Пример для hello.c:

```
h hello include int main n printf return stdio void world
```

## Ответ:
```
#!/bin/bash

file="$1"

identifiers=$(grep -o -E '\b[a-zA-Z]*\b' "$file" | sort -u)

echo "Идентификаторы:"
echo "$identifiers"
```

---

file="$1" сохраняет имя файла<br>
identifiers=$(grep -o -E '\b[a-zA-Z]*\b' "$file" | sort -u) -  находит слова, состоящие только из английских букв, сортирует их и убирает повторы<br>


## Задача 5

Написать программу для регистрации пользовательской команды (правильные права доступа и копирование в /usr/local/bin).

Например, пусть программа называется reg:

```
./reg banner
```

В результате для banner задаются правильные права доступа и сам banner копируется в /usr/local/bin.

## Ответ:

```
#!/bin/bash

file=$1

chmod 755 "./$file"

sudo cp "$file" /usr/local/bin/

echo "Файл '$file' скопирован в usr/local/bin/, права выданы"
```
---

chmod 755 "./$file"` - выдает права на выполнение и чтение для всех, но запись только владельцу<br>
sudo cp "$file" /usr/local/bin/ - копирует файл в системную папку /usr/local/bin/, чтобы его можно было запускать как обычную программу из любого места<br>


## Задача 6

Написать программу для проверки наличия комментария в первой строке файлов с расширением c, js и py.

## Ответ:

```
#!/bin/bash

for file in *.c *.js *.py; do
    line=$(head -n 1 "$file")
    if [[ $line == "#"* || $line == "//"* || $line == "/*"* ]]; then
        echo "Файл $file начинается с комментария"
    else
        echo "Файл $file не начинается с комментария"
    fi
done
```
---

for file in *.c *.js *.py; перебирает все файлы с расширениями c, js, py<br>
line=$(head -n 1 "$file") читает первую строчку файла<br>

## Задача 7
Написать программу для нахождения файлов-дубликатов (имеющих 1 или более копий содержимого) по заданному пути (и подкаталогам).

## Ответ:
```
#!/bin/bash

declare -A duplicats

findDuplicates() 
{
    local dir="$1"
    

    for file in "$dir"/*; do
        if [[ -f "$file" ]]; then
            file=$(basename "$file")
            if [ duplicats["$file"] ]; then
                duplicats["$file"]=$((duplicats["$file"] + 1))
            else
                duplicats["$file"]=1
            fi

            if [ "${duplicats["$file"]}" -eq 2 ]; then
                echo "Файл-дубликат - '$file'"
            fi

        elif [[ -d "$file" ]]; then
            findDuplicates "$file"
        fi
    done
}

findDuplicates "."
```
---
declare -A duplicats - создает переменную ассоциативный массив под именем duplicats<br>
local dir="$1" - создаёт локальную переменную dir и записывает в неё первый аргумент, переданный функции<br>


## Задача 8
Написать программу, которая находит все файлы в данном каталоге с расширением, указанным в качестве аргумента и архивирует все эти файлы в архив tar.

## Ответ:
```
#!/bin/bash

files=( $(find . -type f -name "*.$1") )

tar -cvf "archive.tar" "${files[@]}"

echo "Архив создан"
```
---
files=( $(find . -type f -name "*.$1") ) находит все файлы с нужным расширением и сохранияет их в массив<br>
tar -cvf "archive.tar" "${files[@]}" создает tar-архив со всеми найденными файлами<br>
-c	create - создать новый архив<br>
-v	verbose - показывать, что добавляется<br>
-f	file - следующий аргумент это имя архива<br>

## Задача 9
Написать программу, которая заменяет в файле последовательности из 4 пробелов на символ табуляции. Входной и выходной файлы задаются аргументами.

## Ответ:

```
#!/bin/bash

sed 's/    /\t/g' "$1" > "$2"

echo "Файл исправлен"
```
---
sed 's/    /\t/g' - sed s/что_заменять/на_что_заменять/опции (g - Замените все вхождения строки в файле)<br>
"$1" > "$2" читает из первого аргумента, записывает во второй<br>
s т.е substitute — заменить
/ /	поиск 4-х пробелов
/\t/ - замена на табуляцию
gи.е global — заменить все вхождения в строке, а не только первое


## Задача 10

Написать программу, которая выводит названия всех пустых текстовых файлов в указанной директории. Директория передается в программу параметром. 

## Ответ:
```
#!/bin/bash

for file in "$1"/*; do
    if [[ -f "$file" && ! -s "$file" ]]; then
        echo "Пустой файл: $file"
    fi
done
```
---
for file in "$1"/*; - перебрать все элементы в папке
-f "$file" проверка, что это файл
! -s "$file" - проверка, что он пустой
